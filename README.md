# 🍽️ MealAttend – Smart Meal & Attendance Management Platform

> 🚀 A modern, production-grade platform for managing meals, attendance, organizations, events, and guests — built for Hostels, Educational Institutions, Factories, Offices, Communities, NGOs, and Event Management.

MealAttend simplifies attendance tracking, meal planning, guest management, QR onboarding, analytics, notifications, and reporting through a single powerful platform.

# 🚀 Quick Start

## 📋 Prerequisites

Before running the project, install:

- Flutter 3.35+
- Dart 3.9+
- Android Studio / VS Code
- Android SDK
- Java 17

Verify installation:

```bash
flutter doctor
```

---

## 📦 Install Dependencies

```bash
flutter pub get
```

---

## 🔍 Analyze Project

```bash
flutter analyze
```

---

## 🧪 Run Tests

```bash
flutter test
```

---

## ▶️ Run Application

```bash
flutter run
```

Run on a specific device:

```bash
flutter devices
flutter run -d <device-id>
```

---

## 🧹 Clean Project

```bash
flutter clean
flutter pub get
```

---
